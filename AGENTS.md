# Public documentation site

- This Astro/Starlight site publishes product documentation. Its technical source
  of truth is normally `../../micelclaw-os/docs/`; identify the canonical source
  through that repository's `docs/MAP.md` before authoring pages.
- Keep public docs in English when the site convention requires it, validate with
  `npm run build`, and do not publish or push without explicit approval.

## Planificación de implementaciones

- Para preparar o revisar planes de implementación (no la edición ordinaria de
  contenido), aplica
  `../../micelclaw-os/codex-skills/micelclaw-impact-planner/SKILL.md` y sus
  referencias: relaciones comprobadas antes de tareas, profundidad proporcional
  y wireframes ASCII cuando cambie una interfaz.
- Los planes transversales requieren matriz de impactos y revisión independiente.
  Si falta una fuente o repo consumidor, declara esa parte no inspeccionada;
  no afirmes revisión completa. Revalida el código al ejecutar el plan.
